- **执行器**：本项目用 `kotlin.test` + Kotest property-based (`io.kotest:kotest-property`)；
  暂不引入 Jazzer（Native fuzzer 与 KMP wasmJs target 集成复杂，先把性价比最高的属性测试做扎实）
- **测试位置**：`server/src/test/kotlin/com/communicationcard/server/admin/**FuzzTest.kt`、
  `server/src/test/kotlin/com/communicationcard/server/ServerGameManagerFuzzTest.kt`

  写入 `.quality/check-records.jsonl`（事件类型 `ut_fuzz_record`）— 让下次 UC10 能命中 §约束 A/B/C
- **CI 集成**：在 `.github/workflows/android-ci.yml` 增加 `:server:fuzzTest` job，与 `:server:test` 并行；
  失败阻断 PR（与 `DISP-QP-v1.27-SWD-001` 的 `INST-v1.27-001..005` 的 `enforcement: blocking` 一致）
- **每个 task 估算单位**：S(0.5d) / M(1d) / L(2d) — 含写测试 + CI 接入 + 一轮发现并修复 fuzz crash

## P0 详细 task（必须 v1.27 sprint 内完成）

### F-AUTH-01 · AdminAuthService fuzz
**文件**：`server/src/main/kotlin/com/communicationcard/server/admin/AdminAuthService.kt` (376 LOC)
**风险源**：
- `46be4347 debug(admin): 未捕获的BCrypt IAE路径` — bcrypt malformed hash 导致登录 500
- `cc8515de fix(admin): DUMMY_HASH catch 不再吞 CancellationException` — catch 块语义错误
- `ad74b421 fix(admin): 5 项 admin 模块安全 + 正确性修复` — 集中安全修复

**Fuzz 维度**：
1. `verifyPassword(password, hash)` — Arb.string(0..1024) × {合法 bcrypt, malformed (`$2a$X`, 截断、随机), null, 空, ASCII/UTF-8/emoji}
2. `createSession(userId, role)` — userId 边界（空、超长、SQL meta char）
3. `validateSession(token)` — token 任意字节序列；不得抛非 SecurityException
4. **回归断言**：BCrypt malformed hash → 返回 false 而非抛 IAE（cc8515de 引入的 catch 路径）；
   CancellationException 必须穿透（cc8515de P2）

**测试位置**：`server/src/test/.../admin/AdminAuthServiceFuzzTest.kt`
**目标用例数**：≥ 500，pass_rate=100%
**估算**：M (1d)

### F-AUTH-02 · AdminAuthPlugin hybrid bypass
**文件**：`AdminAuthPlugin.kt` (108 LOC)
**风险源**：
- `b34808fc temp: 临时关闭 admin 鉴权（bypass 模式）` — 引入 bypass 分支
- `c5ba575a fix(admin): hybrid auth bypass + fix CI test failures` — bypass 与正常路径并存

**Fuzz 维度**：
1. 请求头组合：{有 cookie / 无 cookie / 多 cookie / 畸形 cookie} × {bypass on/off} × {expected role}

   bypass-off 下无 cookie 必须 401（不 500）

**回归断言**：bypass 关闭后，AdminApiRoutes 测试 `ec5ccffb` ignore 标记必须可移除
**测试位置**：`AdminAuthPluginFuzzTest.kt`
**目标用例数**：≥ 300
**估算**：S (0.5d)

### F-AUTH-03 · AdminAuthRoutes URI/cookie 编码
**文件**：`AdminAuthRoutes.kt` (138 LOC)
**风险源**：
- `519498ef fix(admin): URI_ENCODING 避免 Ktor RAW cookie 校验 IAE` — 真线 500
- `e705d515 test(admin): 补登录cookie编码回归测试`（已有 1 个回归用例）

**Fuzz 维度**：
1. login body：username/password 含 `;`, `=`, `\r\n`, 空字节，Unicode normalization 形式 NFC/NFD/NFKC/NFKD
2. cookie 编码：URI 字符集全集（含 reserved + percent-encoded 残段）
3. **回归断言**：所有输入必须走 URI_ENCODING 路径，不得回退到 RAW（IAE 不得逃逸）

**测试位置**：`AdminAuthRoutesFuzzTest.kt`（扩展 `e705d515` 已建文件）
**目标用例数**：≥ 200
**估算**：S (0.5d)
